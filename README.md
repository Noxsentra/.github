# Noxsentra GitHub Organization Profile

This repository contains the public GitHub organization profile for **Noxsentra**, an independent cybersecurity, AI security, and threat intelligence research initiative under **Magnexis**.

The public-facing overview is maintained at [`profile/README.md`](profile/README.md).
